# 简历工坊 · 原型 v0.3.0

一个用 Python + Tkinter 写的桌面简历编辑器。它把简历拆成 **7 个固定区域**，每个区域只显示和接收自己的字段；可以在区域内改内容、加删条目、单独调字号和排版，右侧实时预览 A4 单页效果，并导出 Word / PDF。

支持在同一个程序里维护**多份简历**、分别更换**主题色**，并在简历内容区放置个人照片。

核心编辑、预览、JSON 和 Word 导出只依赖 Python 标准库；**个人照片**使用 Pillow，**PDF 导出**使用 ReportLab。

## 运行

环境：Python 3.11+（当前开发环境为 3.11.8）。

```powershell
cd E:\python\简历编辑器
python main.py
```

也可以直接使用本机解释器：

```powershell
E:\python\3.118\python.exe main.py
```

需要照片或 PDF 功能时安装依赖：

```powershell
python -m pip install -r requirements.txt
```

不安装 Pillow / ReportLab 也能正常使用编辑、预览、JSON 和 Word 导出；照片卡片和 PDF 导出会提示安装所需依赖。

启动后会进入**简历库**：第一次只有一份示例简历，点顶部「新建」或「我的简历」菜单可以继续添加。示例头像在 `docs/demo-photo.jpg`，可以用「选择图片」试一下照片功能。

## 已实现的功能

### 1. 多份简历库

- 顶部「我的简历」下拉框显示当前简历和简历总数，点击即可切换。
- 支持新建、切换、复制当前简历、重命名和删除；删除只移出简历库，不删除已经单独保存的 JSON 文件。
- 简历库自动保存到用户数据目录：
  - Windows：`%APPDATA%\ResumeStudio\library.json`
  - 其他系统：`~/.resume_studio/library.json`
- 切换、关闭程序时会立即写入简历库；编辑后约 1 秒自动保存。
- 顶部「保存」仍然把**当前简历**导出为单份 JSON，便于备份、交接和版本管理。
- 至少保留一份简历；最后一份不会被删除。

### 2. 固定的七个区域

| 区域 | 可编辑字段 |
| --- | --- |
| 基本信息 | 姓名、求职意向、电话、邮箱、所在城市、个人网站 / 作品集、个人照片 |
| 教育经历 | 学校、专业、学历、开始时间、结束时间、主修课程 / 经历 |
| 工作经历 | 公司、职位、开始时间、结束时间、工作内容 |
| 项目经历 | 项目名称、项目角色、开始时间、结束时间、项目内容 |
| 专业技能 | 技能名称、技能说明 |
| 获奖荣誉 | 奖项名称、颁发机构、获奖时间、补充说明 |
| 自我评价 | 自我评价正文 |

「基本信息」不显示区域标题，其余区域有标题和分隔线。

### 3. 区域级编辑与排版

- 内容编辑：每个区域有独立表单，支持教育 / 工作 / 项目 / 技能 / 奖项条目的新增、删除、上移、下移；新增后自动定位到第一条输入框。
- 空条目提示：刚添加但尚未填写的条目会在预览中以灰色占位提示出现，不会让空白简历看起来像“页面消失”；导出时会自动忽略空条目。
- 个人照片：在「基本信息」顶部选择 JPG / PNG 等图片，自动裁剪为 25 × 32 mm，显示在简历内容区顶部；支持更换和移除，并随项目 JSON、Word / PDF 导出保存。
- 字体：可使用页面默认字体，也可以给当前区域单独指定字体。
- 字号：分别设置区域标题字号、正文字号。
- 排版：标题对齐、正文行距、区域标题装饰（细下划线 / 左侧色条 / 无装饰）、区域标题加粗。
- 显示控制：隐藏整个区域、隐藏区域标题。
- 页面设置：A4 / Letter、四边页边距、默认字体、主题色、预览纸张颜色。
- 快速预设：「紧凑一页」「舒适阅读」只调整间距、字号和行距，不删除内容。

### 4. 主题颜色

- 顶部「● 主题色」可以直接打开颜色选择器，改完立即刷新预览。
- 「页面设置 → 主题」里提供 7 个快捷主题色（商务蓝、墨绿、酒红、紫罗兰、暖橙、青灰、石墨），也可以分别修改主题色、正文色、辅助文字色、分割线和预览纸张色。
- 主题色会用于区域标题、项目符号、强调信息，并同步到 Word / PDF 导出。
- 每份简历都有自己的主题设置，切换简历会切换到对应配色。
- 「恢复默认主题」可以回到初始配色。

### 5. 实时预览

- A4 单页画布，按宽度自适应，可缩放（42%–135%）。
- 点击预览中的区域，或点击左侧结构栏，都会选中对应区域并打开它的表单。
- 修改内容、字号、行距后自动刷新。
- 内容超出一页时，画布顶部和底部状态栏会提示「内容超出一页」，不会静默裁掉。

### 6. 导入、保存与导出

- 导入：`.docx`、`.txt`、`.md`、`.json`；导入会作为一份新简历加入简历库。
- 保存：顶部「保存」把当前简历导出为原生 JSON，之后可以再次导入继续编辑。
- 导出 Word：根据固定结构生成 `.docx`，A4 页面、字体和区域样式会尽量保留。
- 导出 PDF：使用矢量文字生成 PDF，保留主题色、字体、间距、照片和页边距；内容较多时自动分页。
- 所有表单只渲染白名单字段；导入时未知字段会被丢弃，并给出警告。

### 7. 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+N` | 新建一份简历 |
| `Ctrl+O` | 导入简历 |
| `Ctrl+S` | 保存当前简历 JSON |
| `Ctrl+Shift+S` | 另存为当前简历 |
| `Ctrl+E` | 导出 Word |
| `Ctrl+Shift+E` | 导出 PDF |
| `Ctrl++` / `Ctrl+-` | 放大 / 缩小预览 |

## 导入规则

DOCX 导入是「尽力而为」的结构识别，不保留原文档的复杂版式：

- 识别常见标题别名，例如「教育经历 / 教育背景」「工作经历 / 职业经历」「项目经历 / 项目经验」「专业技能 / 技能特长」「获奖荣誉 / 荣誉奖项」「自我评价 / 个人总结」。
- 姓名取第一段短文本；联系方式行里识别电话、邮箱、城市、个人网站。
- 「公司 / 学校 / 项目名 + 职位 / 专业 / 角色」用 `|`、`｜`、`/` 或 `·` 分隔；日期单独一行也可以识别。
- Word 的项目符号列表会转成多条正文；表格里的文字会按行读取。
- 如果文档中恰好只有一张竖版照片，会自动放入「基本信息」区域顶部；有多张图片或横版图片时不会自动选择，避免把 logo 误当头像。
- 文本框、分栏、页眉页脚、艺术字等不会保留。
- 无法识别的标题或字段不会硬塞进别的区域；会尽量作为当前区域正文保留，并在导入完成后提示。

TXT / Markdown 导入使用同样的标题和字段规则，适合先按模板写纯文本再导入。

## 单页与导出的边界

- 预览只做 **A4 单页**：内容超页时会提示，需要用「紧凑一页」或删减内容。
- **PDF 会自动分页**，不受预览单页限制；如果希望严格一页，请以预览的超页提示为准。
- Word 也按内容自然分页。
- 预览纸张颜色会用于 PDF 页面底色；Word 导出页面仍为白色。
- 导出 Word / PDF 使用程序生成的固定版式，个人照片会嵌入；文本框、分栏、页眉页脚、艺术字等复杂元素不会保留。
- 原型没有多页可视化预览、撤销 / 重做、简历库云同步和多张照片。

## 数据格式

项目 JSON 的顶层结构：

```json
{
  "version": 1,
  "page": {
    "paper": "A4",
    "margin_top": 16,
    "margin_right": 16,
    "margin_bottom": 16,
    "margin_left": 16,
    "background": "#FFFFFF"
  },
  "theme": {
    "font": "Microsoft YaHei UI",
    "text_color": "#253044",
    "accent": "#1D4ED8"
  },
  "sections": [
    {
      "type": "basic",
      "title": "基本信息",
      "data": {"name": "林清越", "job": "高级产品经理 / 数据产品"},
      "style": {"body_size": 10.5, "visible": true}
    }
  ]
}
```

`sections` 中的 `type`、字段和样式键都由 `model.py` 的白名单决定；手动改 JSON 时多出来的键会在读取时被丢弃。个人照片存放在基本信息区域的 `data.photo`，是一个裁剪好的 JPEG data URI，因此项目 JSON 可以单文件带走照片。

多简历库文件的结构：

```json
{
  "schema": "resume-editor/library",
  "version": 1,
  "active": 0,
  "resumes": [
    {
      "id": "随机 id",
      "name": "林清越 · 产品版",
      "custom_name": true,
      "path": "E:\\简历\\产品版.json",
      "resume": {"page": {}, "theme": {}, "sections": []}
    }
  ]
}
```

`path` 是这份简历最近一次单独保存 JSON 的位置，可以为空。简历库由程序自动维护，一般不需要手动编辑。
